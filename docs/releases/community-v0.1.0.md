# CAVRA Community GA v0.1.0 Release Notes

CAVRA Community GA v0.1.0 is the first public Community GA release.

## Release Links

- GitHub Release:
  <https://github.com/Huzefaaa2/cavra/releases/tag/community-v0.1.0>
- Release packet: `docs/release-packets/community-ga-v0.1.0.md`
- Publication record: `docs/community-ga-v0.1.0-release-publication.md`
- Post-release verification:
  `docs/release-verifications/community-v0.1.0-post-release-verification.md`
- Verification runbook: `docs/community-release-verification-runbook.md`

## Highlights

- Public Community Edition package and source distribution are available from
  GitHub Releases.
- Release packet gates passed for public boundary validation, policy signing,
  policy validation, runtime modes, golden decisions, Evidence Console,
  deployment validation, Go runtime readiness, documentation, and CI evidence.
- Post-release verification confirmed artifact downloadability, SHA-256
  checksums, clean wheel installation, and `cavra version` output.
- Enterprise source code, paid policy packs, SaaS backend implementation,
  license-service internals, private keys, and customer records are not part of
  the public Community release.
