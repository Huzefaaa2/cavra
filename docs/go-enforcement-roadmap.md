# Go Enforcement Roadmap

1. Stabilize the Python enforcement interface.
2. Generate clients from `proto/cavra/enforcement/v1/enforcement.proto`.
3. Implement a Go runtime prototype under `go/cavra-runtime/`.
4. Add parity tests for file, command, Git, MCP, approval, and evidence decisions.
5. Ship Go as optional local backend.
6. Make Go production default only after audited parity and deployment tests.
