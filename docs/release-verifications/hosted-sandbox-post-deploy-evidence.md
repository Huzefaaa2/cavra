# Hosted Sandbox Post-Deploy Evidence Contract

Status: workflow_enforced

This public-safe contract defines the runtime deployment evidence generated
after `.github/workflows/deploy-sandbox.yml` publishes the CAVRA GitHub Pages
portal and the hosted browser smoke check passes.

## Generated Artifact

The workflow uploads an artifact named
`cavra-hosted-sandbox-post-deploy-evidence` containing:

- `.cavra/deploy-evidence/hosted-sandbox-post-deploy-evidence.json`
- `.cavra/deploy-evidence/hosted-sandbox-post-deploy-evidence.md`

The artifact is generated by
`scripts/generate-hosted-sandbox-deploy-evidence.py` and validated by
`scripts/validate-hosted-sandbox-deploy-evidence.py`.

## Runtime Fields

The generated packet records:

- Deployed Pages URL.
- GitHub Actions workflow run URL.
- Workflow run id and attempt.
- Commit SHA and ref.
- Hosted smoke status from `npm run validate:sandbox:hosted`.
- Verification source references.

## Public Safety Boundary

The generated artifact records public GitHub Pages deployment metadata and
hosted smoke status only. It must not include customer data, license secrets,
private registry credentials, private trial package tokens, or Enterprise source
code.
