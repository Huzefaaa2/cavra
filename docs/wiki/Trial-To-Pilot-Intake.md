# Trial To Pilot Intake

This page describes the public-safe intake flow for converting a CAVRA
Community or Trial evaluation into an Enterprise pilot or SaaS onboarding path.

## Template

Use:

```text
examples/demos/trial-to-pilot-intake/trial-to-pilot-intake-template.json
```

Schema version: `cavra.trial_to_pilot_intake.v1`.

## Readiness Areas

- Repository and transparent agent scope
- CI/CD required check and evidence path
- Non-production connector routes
- SSO/RBAC ownership
- Evidence retention and archive model
- Enterprise or SaaS commercial handoff

## Boundaries

The public repository may include templates, API contracts, readiness scoring,
synthetic examples, and documentation.

Customer responses, license keys, connector credentials, private policy packs,
Enterprise source, SaaS backend source, production tenant IDs, and commercial
terms must remain in private Enterprise, customer-owned, or SaaS systems.
