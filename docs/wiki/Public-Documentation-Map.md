## Internal Evidence And Archive

Development and testing artifacts are not the first path for new users. Historical
implementation notes, legacy generated wiki copies, release verification packets,
and generated validator outputs are indexed in the repository archive:

- [Development And Testing Artifacts Archive](https://github.com/Huzefaaa2/cavra/tree/main/docs/archive/development-and-testing-artifacts)
- [Release verification evidence](https://github.com/Huzefaaa2/cavra/tree/main/docs/release-verifications)

## Documentation Rule

Public readers should start with the README, product website, wiki textbook, and
CLI reference. Development artifacts, generated validation packets, historical
closeout notes, and release evidence should stay in archive or evidence folders
unless they are directly linked from this public documentation map.
