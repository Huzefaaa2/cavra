# CAVRA Brand Assets

CAVRA includes a professional logo and thumbnail asset set for documentation, dashboards, README surfaces, and social previews.

- `assets/brand/favicon.svg`

## Usage

Use the horizontal logo for documentation and README pages. Use the mark for compact dashboard navigation and favicons. Use the thumbnails for GitHub previews, release notes, and enterprise presentation covers.

## Enterprise Value

Consistent brand assets make CAVRA easier to recognize in enterprise rollout material, internal dashboards, design reviews, and audit documentation.
