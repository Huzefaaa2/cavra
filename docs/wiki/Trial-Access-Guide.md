# CAVRA Trial Access Guide

CAVRA Trial is a temporary evaluation path for CAVRA Managed or Enterprise
Subscription capabilities. It is not a separate code edition.

Start here:

- [CAVRA Trial Portal](https://cavra-trial.mind-ops.cloud/)
- [CAVRA Trial Field Guide](CAVRA-Trial-Field-Guide.md)

## Trial Flow

1. Submit an evaluator request with business context and evaluation goal.
2. Complete operator review.
3. Receive hosted access or time-limited entitlement material through a controlled channel.
4. Run one guided use case with one repository or workflow, one risky AI-agent action, one approval, one evidence bundle, and one AISPM/report review.
5. Close the trial with expiry, revocation, evidence archive status, feedback, and pilot decision.

Do not place trial licenses, package tokens, private URLs, or screenshots of
secret material into source control or public documents.
