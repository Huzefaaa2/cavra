## Summary

CAVRA Community AISPM v1.0 adds the public-safe AI Security Posture Management
dashboard, CSO report center, launch readiness evidence, pilot control
readiness, and trial lab notebook visuals to the Community portal.

The public site uses sample or local public-safe activity. Live multi-tenant
ingestion, authenticated dashboards, signed approvals, private policy packs,
tenant telemetry, private package access, and Enterprise report delivery remain
Enterprise-only.
