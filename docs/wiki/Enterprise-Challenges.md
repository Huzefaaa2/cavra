# Enterprise Challenges

CAVRA addresses the following enterprise risks:

- Secret exposure.
- Unsafe infrastructure changes.
- Direct Git push and review bypass.
- Dangerous shell commands.
- Unknown MCP server and tool sprawl.
- Audit gaps.
- Identity ambiguity.
- Approval bypass.
- Excessive agency.
- Prompt-injection-induced tool misuse.

The control model is pre-action enforcement plus audit-ready evidence.
