# Enterprise FAQ

## Is Enterprise source public?

No. Enterprise source code is maintained in a private repository.

## Does Community require a license?

No. Community runs without a license key.

## Can public CAVRA load Enterprise modules later?

Yes. Public hooks can dynamically load a private `cavra_enterprise` package or
Enterprise plugins when installed and licensed.

## Are trial keys public?

No. Trial keys and license validation belong to private services.
