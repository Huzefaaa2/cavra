# Enterprise Adoption

Adopt CAVRA in phases: audit-only visibility, enforce secret and protected-branch controls, route infrastructure and IAM changes for approval, require PR attestation, export evidence to SIEM/ITSM, then expand to MCP trust and agent identity governance.

Regulated repositories should start with `cavra-cavra-ai-agent-baseline`, add industry packs, and require CAVRA evidence for AI-assisted pull requests.
