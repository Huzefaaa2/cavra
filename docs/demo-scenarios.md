# Demo Scenarios

Flagship: Before the Agent Acts. The simulated AI agent tries to read `.env`, modify `iam/admin-role.tf`, run `terraform plan`, run `terraform apply -auto-approve`, use an unknown filesystem MCP server, push to `main`, and open a PR. CAVRA blocks, allows, or requires approval before each action and generates evidence.

Final closeout trial: `examples/demos/final-closeout-trial/` contains a synthetic final closeout evidence package for customer onboarding. Use it with the trial walkthrough, sample evidence guide, and sales-engineering demo script to explain release closeout, retention health, retry planning, release criteria, and the Community-to-Enterprise upgrade path.

Additional narratives: CAVRA for Claude Code, CAVRA for GitHub Copilot Agent, CAVRA for MCP Security, CAVRA for Banking AI Coding Governance, and CAVRA in CI/CD.
