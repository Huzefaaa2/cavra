# Trial To Pilot Intake

This folder contains a public-safe template for converting a CAVRA Community or
trial evaluation into a scoped Enterprise pilot or SaaS onboarding motion.

Use `trial-to-pilot-intake-template.json` as a synthetic starting point. Do not
commit customer responses, commercial terms, private connector routes, license
keys, signing keys, production tenant identifiers, or customer evidence to this
public repository.
