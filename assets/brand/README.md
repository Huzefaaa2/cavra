# CAVRA Brand Assets

This folder contains repo-native CAVRA brand assets for documentation, the sandbox console, README surfaces, and release previews.

## Primary Assets

- `cavra-mark.svg`: square runtime authority shield mark.
- `cavra-logo-horizontal.svg`: primary README and documentation wordmark.
- `cavra-logo-stacked.svg`: square dashboard and presentation logo.
- `cavra-thumbnail.svg`: 1280 x 640 product thumbnail.
- `cavra-github-social-preview.svg`: 1200 x 630 repository/social preview.
- `favicon.svg`: compact browser icon.

PNG exports are generated under `assets/brand/png/` for systems that do not render SVG.

## Usage

Use the horizontal logo for README and long-form documentation. Use the mark or favicon in compact UI surfaces. Use thumbnails for GitHub social previews, release notes, and deck covers.

The visual direction is enterprise-focused: dark operational surface, teal runtime authority, blue integration signal, and gold approval/evidence accent.
